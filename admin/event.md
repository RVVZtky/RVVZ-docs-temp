# Správa eventu (RVVZtky)

Nastavuje se zde:
- Název
- Popis (Fungují zde html tagy (`<a></a>`, `<strong></strong>`, atd...).)
- poznámka k programům (pokud je zadaná, zobrazí se na stránce se seznamem programů)
- Lokalizace
- Začátek a Konec
- reply-to email (všechny emaily, které přihlašovadlo vygeneruje k této RVVZtce, budou mít nastavené toto reply-to)

Dále nastavení:
- Registrace otevřena (pokud je False, zakáže dalším uživatelům signup na RVVZtku)
- Přihlašování na programy otevřeno (pokud je False, zakáže uživatelům přihlašovat/odhlašovat se na programy)
- Přihlašování na jídla otevřeno (pokud je False, zakáže uživatelům přihlašovat/odhlašovat se na jídla)
- Stránka ubytování zapnuta (pokud je False, nebude se zobrazovat odkaz na stránku spaní)
- Stránka jídel zapnuta (pokud je False, nebude se zobrazovat odkaz na stránku jídel)
- Stránka plateb zapnuta (pokud je False, nebude se zobrazovat odkaz na stránku plateb a nepůjdou generovat faktury)


_Pro přístup k datům není potřena žádná [permise](https://github.com/RVVZtky/RVVZ-docs-temp/blob/master/permissions/README.md)_   \
_Pro úpravu dat je potřeba [permise](https://github.com/RVVZtky/RVVZ-docs-temp/blob/master/permissions/README.md) event\_edit_
